# PharmaChain - Secure Pharmaceutical Supply Chain Tracking System

**Course:** 24CYS401 - Secure Software Engineering
**Exam:** End Semester Laboratory Examination
**Domain:** Pharmaceutical Supply Chain (Manufacturer -> Distributor -> Warehouse -> Retailer -> Customer)

## Tech Stack
- Backend: Python 3.13 + FastAPI
- Database: PostgreSQL
- Ledger: Hyperledger Fabric (permissioned)
- Container: Docker + Kubernetes (Minikube)
- CI/CD: GitHub Actions
- Security: mTLS, PKI, RBAC+ABAC, SHA-256 hash chain, digital signatures

## Traceability Thread (SR-03)
Every ownership transfer must be digitally signed, hash-chained, and audit-logged.
